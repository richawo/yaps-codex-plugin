# Yaps Meeting Transcription for ChatGPT Desktop, Claude, and Codex

This local-first plugin must be able to reach the Yaps engine installed on the
user's computer. If you are using ChatGPT web or a cloud session,
[download or open ChatGPT desktop](https://chatgpt.com/download/) and retry in a
local-capable Work or Codex session. You can also access this feature directly
in the Yaps application. The workflow checks actual Yaps reachability instead of
relying on a user-agent guess or assuming that Yaps is uninstalled.

Turn meeting, interview, podcast, webinar, or call recordings into timed, speaker-labelled transcripts using Yaps desktop. The result stays editable in Yaps and can also be corrected, reassigned, renamed, and exported from the AI client.

[Download Yaps](https://yaps.ai/download), open the app, and sign in before using the plugin. Yaps has no free tier: meeting transcription requires an active free trial or Yaps Pro. Yaps confirms trial eligibility and the current offer inside the app.

The plugin uses the CLI already packaged inside Yaps; no separate CLI install or Agent Access permission is required. Install Meeting from the Yaps Features tab. Sherpa provides the cross-platform engine and accepts an optional participant count. Apple Silicon users can also install MOSS for faster local processing of longer meetings; MOSS is not shown on unsupported platforms.

Audio files are processed directly. For a video, Yaps first extracts its audio and then creates the same editable meeting project. The plugin does not upload a recording merely because it is installed.
