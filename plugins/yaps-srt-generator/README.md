# Yaps SRT Generator for Codex

Yaps SRT Generator creates a timestamped `.srt` subtitle file from an existing audio or video file through the local Whisper component supplied by Yaps desktop.

[Download Yaps](https://yaps.ai/download), finish any sign-in inside the app, then choose **Yaps → Settings → General → Local AI integrations → Install CLI**. Enable Subtitles under Yaps Features when prompted. FFmpeg is required for media extraction.

The plugin processes only the file the user selects and does not upload media merely because it is installed. For a plain-text transcript without subtitle timings, use Yaps Transcription.
